# Картинки курса

Для новых материалов используйте папки **A1.1** и **A1.2**: уровень → модуль → урок. Названия взяты из актуального A1_САМЫЙ_САМЫЙ.md. Созданы 14 модулей и 98 уроков: 53 в A1.1 и 45 в A1.2.

Например: `A1.2/Модуль 05. Сейчас/Урок 04. Учёба/`.

Откройте нужный урок и выберите **Add file → Upload files**. Все картинки этого урока можно хранить вместе. Имена новых файлов делайте понятными: `words-study.png`, `speaking-01.png`, `listening-01.png`, `practice-01.png`. Для нового варианта используйте новое имя, чтобы не заменять картинку в ранее выданной работе.

Загрузка файла добавляет его в репозиторий; для показа в упражнении нужно также подключить его путь в содержимом урока. Пустой служебный файл сохраняет папку в GitHub; после загрузки картинок его можно оставить.

## Текущие картинки

В папке **Текущие** собраны все 141 существующее изображение, включая файлы из корня и assets. Их исходные имена и пиксели сохранены. Прежние подпапки оставлены внутри этой общей папки, чтобы различать одинаковые имена и происхождение файлов. Новые папки уроков предназначены для дальнейшего наполнения.

32 копии остаются по прежним адресам: на них ссылаются уже выданные домашние работы. Новые уроки и новые домашки используют пути внутри Images/Текущие. Список прежних адресов, новых путей и необходимых копий находится в [image-paths.json](image-paths.json). Эти копии сохраняют работоспособность старых ссылок; изображения не перегенерировались и не сжимались.
